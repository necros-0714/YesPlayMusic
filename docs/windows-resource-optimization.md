# Windows 11 资源优化版

基于用户提供的 v0.4.11 源码与原版 `YesPlayMusic.0.4.10.exe`，本地版本为 `0.4.11-optimized.1`。原 EXE 保持原样，源码修改前的副本保存在 `.dev/baseline/`。

## 使用

退出原播放器后，运行 `dist_electron/YesPlayMusic-0.4.11-optimized.1-x64-portable.exe`，或使用同目录的 `*-Setup.exe` 安装版。两者均为 Windows x64。

设置中的“节能模式”默认开启：歌词最高 30 FPS，暂停时最高 15 FPS，关闭非当前行模糊与动态背景。取消该选项可恢复动态背景与模糊效果，歌词最高 60 FPS。音质设置不变。

本地优化版不自动接收上游更新，避免优化源码被原版安装包覆盖。

## 修复

- 音频 Blob 清理的 `for...in` 实际遍历数组下标，旧音频没有释放；改为释放真实 URL。
- 下一首预缓存只检查索引并写磁盘，不加载缓存音频或创建预播 Blob。
- 启动时缓存大小通过 IndexedDB 游标逐条统计，避免用 `toArray()` 同时读入全部音频。
- 同歌曲并发下载合并，覆盖缓存时扣除旧大小；缓存清理串行执行，清空缓存等待提交并阻止旧下载写回。
- 歌词页关闭、窗口隐藏或最小化时销毁歌词视图与 WebGL 背景；再次打开按当前播放进度恢复。Win11 可见性由原生窗口 IPC 与页面事件共同判断。
- 移除歌词组件销毁后的键盘与全屏监听；图形渲染器与只读歌词数据避免 Vue 深层观察。
- 路由页面缓存最多保留三个组件；关闭歌词后正确恢复页面滚动。
- 跳过重复播放器状态赋值，播放进度使用独立保存路径；缓存音频不再额外请求三种尺寸封面。
- 歌曲详情按主键读取缓存，同一调用只发送一次网络请求。

## 验证与测量

直接运行用户提供的原版免安装 EXE 与新生成的优化版免安装 EXE。使用相同 Electron 13.6.9、1440×840 窗口、独立测试配置、60 秒本地静音 WAV、120 行逐字歌词，每种状态采样 8 秒。原版测试选择 AMLL 动态背景，优化版使用默认节能模式，因此数据体现修复与视觉开销调整的共同效果。未使用用户登录或缓存；在线账号歌曲播放没有验证。

| 逐字歌词播放 | 原版 | 优化版 | 变化 |
| --- | ---: | ---: | ---: |
| 所有应用进程私有提交内存 | 553.2 MiB | 438.2 MiB | -20.8% |
| 所有应用进程工作集总和 | 575.2 MiB | 515.8 MiB | -10.3% |
| 渲染主线程活动时间 / 8 秒 | 6.076 秒 | 3.442 秒 | -43.4% |
| 渲染脚本执行时间 / 8 秒 | 0.465 秒 | 0.176 秒 | -62.2% |
| 样式重算时间 / 8 秒 | 1.878 秒 | 0.577 秒 | -69.3% |

首次启动空闲工作集原版约 365.5 MiB，优化版约 346.7 MiB。Electron 浏览器运行时的基础占用仍然存在，不能保证所有场景都降到固定内存。私有提交内存、工作集与任务管理器默认内存列是不同指标；工作集总和包括共享页。测试为同机单次离线样本，真实网易云曲目、长歌单、FLAC、窗口大小、缓存量与显卡会影响结果。测量脚本可重复运行，原始 JSON 位于 `.dev/original-performance.json` 与 `.dev/optimized-performance.json`，另汇总保存在 `docs/windows-performance-results.json`。

连续 40 次创建音频后仅当前 Blob 可访问，39 个旧 URL 均失效。6 项真实 IndexedDB/Blob 检查与 24 项歌词回归检查通过。开关歌词五轮后仅保留一个当前实例，关闭后歌词与背景画布数量均为零。实际优化 EXE 内已验证播放、暂停后恢复、跳转进度、最小化后继续播放与释放歌词、恢复窗口、节能模式开关及背景画布销毁。修改文件的 ESLint 检查通过，安装版已成功打包但没有在本机执行安装。

## 重新构建

在 PowerShell 中运行：

```powershell
& .\tools\optimization\build-win.ps1
```

本机已准备好依赖、Electron 与打包工具，脚本复用 `.dev/toolchain/` 和 `.dev/builder-cache/`。普通联网环境可使用 Yarn 1 安装锁定依赖后，设置 `NODE_OPTIONS=--openssl-legacy-provider` 并执行 `yarn electron:build-win`。本次将锁文件的镜像域名统一为 npm 官方域名，保持版本与完整性校验不变。

安装包保留项目许可证。原始 Electron 版本未升级，本次重点为应用资源管理、歌词特效与后台工作。
